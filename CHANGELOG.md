# Insight Downloader 0.7.3

Срочное техническое обновление Insight Downloader после версии 0.7.2: исправлена работа с качеством YouTube, улучшена упаковка PO Token provider и автоматическая подготовка FFmpeg/ffprobe.

## Что нового

### YouTube

- Исправлена ситуация, при которой YouTube мог показывать только низкие разрешения вместо 1080p, 1440p и 4K.
- Insight больше не ограничивает YouTube только клиентом `mweb`.
- Добавлена комбинированная стратегия клиентов `default`, `web_embedded` и `mweb`.
- WPC PO Token provider продолжает использоваться для получения GVS PO Token.
- Для WPC явно передаётся путь к установленному Chrome/Chromium, если браузер найден.
- Для YouTube принудительно разрешено получение PO Token через доступный provider.
- В production-сборку теперь явно включаются `yt_dlp_plugins.extractor.getpot_wpc` и необходимые компоненты `nodriver`.
- Добавлена проверка WPC provider перед сборкой релиза, чтобы сломанный YouTube backend не попадал в готовый установщик.
- `nodriver` закреплён на совместимой с WPC версии `0.50.3`.

### Видео

- Исправлен выбор форматов высокого качества.
- Для 1080p, 1440p и 2160p приложение корректно использует отдельный видеопоток и лучший доступный аудиопоток.
- FFmpeg объединяет адаптивные видео- и аудиопотоки в итоговый MP4.
- Для MP4/M4A добавлен приоритет совместимых потоков с автоматическим fallback на другие доступные форматы.
- Сохранён выбор конкретного разрешения и режим «Лучшее доступное».

### Media Runtime

- FFmpeg и ffprobe по-прежнему не раздувают основной установщик.
- Media Runtime теперь автоматически подготавливается в фоне после первого запуска production-версии.
- Если пользователь начинает загрузку во время подготовки Media Runtime, Insight ожидает завершения установки и продолжает загрузку автоматически.
- Если фоновая установка не удалась, остаётся обычный диалог повторной установки.
- Media Runtime больше не привязан жёстко к версии приложения: если runtime для текущего тега ещё не опубликован, Insight использует runtime из последнего доступного GitHub Release.
- Установка FFmpeg/ffprobe выполняется через временные файлы с последующей заменой, чтобы приложение не увидело частично записанный executable.
- `setup_windows.cmd` и `build_release.cmd` умеют автоматически получить Media Runtime из последнего опубликованного релиза, если локальных `ffmpeg.exe` и `ffprobe.exe` ещё нет.

### GitHub и релизы

- Репозиторий `mikemandi/Insight-Downloader` теперь задан как production fallback внутри приложения.
- `build_release.cmd` больше не должен спрашивать репозиторий, если отсутствует `.git` или локальный `release_config.json`.
- `publish_release.cmd` теперь умеет публиковать релиз без локальной папки `.git`, используя явно настроенный GitHub repository.
- Система автообновлений и загрузка Media Runtime используют один production repository.

### Исправления и улучшения

- Улучшены сообщения об ошибках PO Token, QuickJS и FFmpeg.
- Сохранена компактная архитектура PySide6-Essentials + QuickJS-NG + отдельный Media Runtime.
- Интерфейс и дизайн-система 0.7.2 оставлены без глобальных изменений.
